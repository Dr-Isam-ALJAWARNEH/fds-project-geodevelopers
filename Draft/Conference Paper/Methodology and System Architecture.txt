Methodology

This section explains the methodology implemented to analyze the spatial pollution data and generate effective minimum spanning tree path for optimizing pollution monitoring networks.

It is essential to collect a large data set during different timestamps or from different resources. A large data set has been collected, analyzed based on the available environmental and functional variables to select the best pollution columns, filtered to remove the missing values and outliers, multiple tables was generated based on different criteria’s grouping, sampling and clustering to generate the best MST path, and provide a recommendation to increase / decrease the number of required sensor in each cluster. The reason behind each process is explained in the following subsections.

A. Geohash Encoding
Geohash, introduced in 2008 by Gustavo Niemeyer, is simply an approach to encodes the geographic coordinates (latitude and longitude) into a short numerical string to aggregate nearby points into grid-like regions [1]. Geohash precision varies based on the encoded characters, where the larger characters is, the higher spatial resolution and the smaller area represented by the grid [2]. This method is effective in studies involving a proximate spatial analysis as it simplifies and speed up the data querying process. In this study, it is used to group the sensors data and get the average pollution level. 

B. Sampling
Sampling is essential part of data science, as it involves the process of selecting a subset of observation from population or large dataset. Samples enable scientist to reduce the data volume while preserving the population characteristics, ensure proper representative, minimize redundancy and optimize resources. Some of the important methods of sampling are sampling with replacement, when the sampled individual is selected from array and it possible to select the same sample again, and the sampling with-out replacement, when the sampled individual is not in returned to the population until all required individuals are selected [3], which will be used in this study to select a random sample from population to balance the representative preservation and allow efficient clustering process. 


D. K-Means algorithm
The K-Means clustering algorithm is a dividing clustering method that separates data into K number of groups. The K-means algorithm is particularly effective at rapidly and efficiently clustering large amounts of data.
K-Means clustering algorithm is an unsupervised clustering algorithm in which the centroids are initialized with any number. The K-Means algorithm is very sensitive to the starting vertex. It is used to analyze air pollution to improve both the correctness and proficiency of the clustering process. [5]
The goal is to find a set of k points in ℝᵈ, called centers, that minimizes the mean squared distance between each data point and its closest center given a collection of n data points in real d-dimensional space, ℝᵈ, and an integer k. This clustering technique falls under variance-based clustering, and the metric is often called squared-error distortion [7].

E. DBSCAN algorithm

DBSCAN was invented by Ester et al. in 1996. A clustering algorithm that clusters points based on whether they fall into a predetermined neighbourhood with other points. This method can cluster points with more complicated shapes and is not sensitive to initial values.  This algorithm does not require clustering for all points, letting those points that do not fall into a particular cluster be defined as noise. [6]
DBSCAN initiates the identification of a cluster with an arbitrary point p and thereafter retrieves all points that are density-reachable from p concerning Eps and MinPts. If p is a core point, this procedure produces a cluster with respect to. Eps and MinPts. If p is a border point, no points are density-reachable from p, and DBSCAN proceeds to the subsequent point in the database.
Due to the utilization of global values for Eps and MinPts, DBSCAN may merge two clusters into a single cluster, if clusters of different densities are in nearby to one another [8] .


F. Dijkstra’s algorithm
The Dijkstra approach determines the shortest path in weighted graphs (networks) by iteratively selecting the node with the smallest distance and updating its adjacent nodes [9].


G. Kruskal's algorithm
Alternative solution, Kruskal's algorithm, introduced in 1956 by Joseph Kruskal is used to compute the minimum spanning tree (MST) based on the weighted path without cycles. Kruskal's algorithm starts by calculating the weight between all the possible vertices pairs. After that, the weighted edges are sorted in ascending order, and the shortest edge is added to the execution query, then the second shortest edge is selected and evaluated if it can be added to the MST or it will perform a cycle, then the process is repeated until all vertices are connected without cycles [4]. The algorithm is effective for geospatial optimization tasks and network designs. In this study, the minimum spanning tree is used to find the best path to connect all sensors based on the spatial distance and the weighted pollutions average for optimizing pollution monitoring networks.
